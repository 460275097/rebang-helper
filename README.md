## ✨ 功能特性




- **40+ 热榜聚合**：今日头条、微博、知乎、B站、抖音、百度、腾讯新闻、IT之家、虎扑、豆瓣、36氪、吾爱破解、GitHub 上升榜等，一次看全
- **聚合模式**：多源混合去重，按综合热度排序，也可按来源分组浏览
- **三种视图**：有图卡片 / 无图紧凑列表，每条新闻标题完整显示
- **每个源独立设置**：显示条数 1~50 任意整数字、可改抓取地址、可增删源、可拖动排序
- **收藏夹 & 浏览记录**：喜欢的新闻一键收藏
- **关键词搜索**：全站内容即时过滤
- **一键翻译**：右上角开关，外文标题自动翻译
- **语音朗读**：只读新闻标题，语速可调，解放双眼
- **转发 & 收藏按钮**：每条新闻都可转发
- **主题自定义**：深色/浅色模式、7 种主题色、自定义字体字号、背景图
- **单实例运行**：重复双击不会多开，自动唤起已有窗口
- **关闭最小化到托盘**：右下角常驻，双击图标随时打开
- **网页版同款体验**：手机浏览器打开网页版，收藏云端同步
