- **292 个内置热榜源**：今日头条、微博、知乎、B站、抖音、百度、腾讯新闻、IT之家、虎扑、豆瓣、36氪、吾爱破解（精品软件区·Android）、GitHub 今日上升、财联社、东方财富、新浪财经、上交所、国务院文件、中国人民银行、财政部、国资委、财新、央视新闻、国家统计局、中房网、现代城市研究、规划师、素材资源、ModelScope 模型榜、卫星通讯社、医学顶刊、各学科期刊、开源项目等，一次看全

## 🤖 题目缓存 × AI 智能体分析

从 V8.0.5 起，软件每天自动把抓到的标题存成本机文件。这些文件是开放格式，可以直接丢给 AI 智能体（如 WorkBuddy、其他 AI 助手）读取，用来做**每日热点推送、趋势分析、经济形势跟踪、股票标的关联**等任务。

### 第一步：复制缓存路径给 AI

1. 打开软件 → **设置 → 「题目缓存」**
2. 点 **「📋 复制路径」** 按钮，缓存目录地址就复制到剪贴板了（也可以点「📂 打开目录」自己看一眼，目录不存在时会自动创建）
3. 把这句话发给你的 AI 智能体：

```
这是热榜助手本机的题目缓存目录：
C:\Users\你的用户名\AppData\Roaming\热榜助手V2\titles
请读取里面的 JSONL 文件，帮我……（按需填：每天汇总推送 / 分析经济形势 / 跟踪我关注的公司）
```

> 想换个更好找的位置？在同一区块把目录改成 `D:\热榜缓存` 之类的自定义路径，点「保存」即可，旧数据会自动迁移追踪。

### 第二步：AI 会看到什么

```
titles/
├── README-AI.txt        ← 数据格式说明，AI 读到它就自己知道字段怎么用
├── 2026-11-19/
│   ├── 财经.jsonl        ← 每天一个文件夹，按分类分文件
│   ├── 综合.jsonl
│   └── _all.jsonl        ← 当天全部分类合并流，一次读一天
└── 2026-11-20/
    ├── 财经.jsonl
    └── _all.jsonl
```

每行一条独立的 JSON 对象（JSONL，可按行流式解析）：

```json
{"ts": "2026-11-20 09:31:05", "cat": "财经", "src": "华尔街见闻", "title": "……", "url": "https://……", "heat": 9865}
```

| 字段 | 含义 |
| --- | --- |
| `ts` | 抓取时间 |
| `cat` | 新闻源所属分类（多分类用 / 连接） |
| `src` | 新闻源名称 |
| `title` | 标题（最长 160 字） |
| `url` | 原文链接（同一天内唯一，可做去重主键） |
| `heat` | 热度数值（可能为 null） |

### 可以让 AI 建立的自动化任务举例

- **每日热点推送**：每天早上让 AI 读昨天的 `_all.jsonl`，去重后汇总 Top 20 热点，推送到微信 / 邮件
- **经济形势跟踪**：只读「财经 / 宏观政策」等分类文件，统计关键词频率变化，生成每日简报
- **标的关联提醒**：维护一张关注词表（公司名 / 股票简称），AI 每天扫描 `title` 命中情况，命中就提醒你
- **趋势复盘**：按日期顺序读多天，统计某个话题的出现频率曲线

> 提醒：标题是二手信号，AI 的分析结论适合做研究线索参考，不构成投资建议。

## 🧩 源码说明

| 文件 | 作用 |
| --- | --- |
| `app2.py` | 单文件后端（Python 标准库 `http.server`）+ 全部抓取解析器 + 配置迁移 |
| `ui2.html` | 前端整站（HTML/CSS/JS 一体，无框架、无外链） |
| `ui_embed.py` | 由 `ui2.html` 压缩生成的内嵌页面（**改完 html 必须重新生成**） |
| `build_all.py` | 一键打包 exe（自动重生成 `ui_embed.py` → PyInstaller 单文件，版本号取自 `VERSION`） |
| `build_apk.py` | 一键打包安卓壳 APK |
| `bump.py` | 一键升版本号（`ui.html` / `version_info.txt` / APK / WebView 参数） |
| `version_info.txt` | exe 文件属性（产品版本等） |
| `ic_launcher.ico` | 程序图标（与安卓端同源，16~256 多尺寸） |
| `VERSION` | 当前版本号 |

```bash
# 本地跑起来（需要 Python 3.10+，只用标准库）
python app2.py

# 打包 exe（需要 pip install pyinstaller）
python build_all.py
```

安卓端是 WebView 壳（原生 TTS、文件选择、分享面板、边缘返回都在壳里），界面复用同一份 `ui2.html`，因此三端永远同步。
