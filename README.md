## ✨ 功能特性

### 📰 热榜聚合
- **200+ 热榜源**：今日头条、微博、知乎、B站、抖音、百度、腾讯新闻、IT之家、虎扑、豆瓣、36氪、吾爱破解、GitHub 上升榜、财联社、东方财富、新浪财经、上交所、国务院文件、ModelScope 模型榜、卫星通讯社、医学顶刊、医疗期刊、运动科学、经济期刊、开源项目等，一次看全
- **15 大分类**：综合 / 财经 / 娱乐 / 科技 / 社区 / 国际新闻 / 小说 / 币圈 / 资源 / Agent / 医学顶刊 / 医疗期刊 / 运动科学 / 经济期刊 / 开源，分类可自建、改名、删除、隐藏、拖拽排序
- **本地新闻**：设置自己的省 / 市，随时看本地新闻榜
- **总排行**：全部新闻源按阅读 / 评论 / 热度合并大排行
- **接口优先**：能走官方 JSON 接口的源绝不爬页面（微博、B站、知乎、抖音、虎扑、头条、财联社等），抗改版、速度快、更稳定；接口失效自动降级到备用通道
- **多线程并发抓取 + 缓存秒开**：热缓存 0.1 秒打开，冷启动全量上百源约 7 秒；没抓到数据的源保留上次内容并提示，不再白屏
- **每个源独立设置**：显示条数 1~50 任意整数、可改抓取地址、可增删源、可拖动排序

### 🖥️ 两种视图
- **总览看板**：所有源拼成一屏看板，单行 4 列、板块等大，标题两行完整显示，鼠标悬停显示全题；板块底部「浏览更多」直达单源全部新闻
- **紧凑列表**：排名 + 标题 + 热度，一行一条，适合快速刷榜
- **打开默认进入聚合热榜总览看板**，视图切换即时生效

### 🔍 阅读体验
- **关键词搜索**：输入即筛，看板 / 列表 / 单源 / 收藏 / 浏览记录全部实时过滤
- **一键翻译本页**：整页标题中英对照，自动分批补齐不漏条；桌面版支持谷歌 / 百度 / 有道引擎（百度、有道需自备开放平台 Key，未配自动降级）
- **语音朗读（三重引擎）**：看板模式逐源连读（每源 10 条、播报源名、序号自动计数）；引擎自动切换：电脑端走系统语音 / 在线神经网络语音，安卓 App 走原生语音 / 云端在线语音，没装语音库也能出声；语速可调（默认 1.25 倍）、中途调速不打断
- **收藏夹 & 浏览记录**：喜欢的新闻一键收藏，手机端云端同步
- **字号 / 字体调节真正生效**：14 款常用字体 + 自定义字体，标题、热度、榜单全部跟随缩放
- **主题自定义**：深色 / 浅色模式、7 种主题配色、背景图片 + 透明度 0~100%（顶栏与新闻框一起透出背景）

### ⚙️ 其他
- **单实例运行**：连点多次也不会多开，新版本启动自动关闭旧版本，重复打开时自动聚焦已有窗口、不再叠出第二个窗口
- **新闻源管理**：一键全开、一键载入默认源、锁定新闻源、新增自定义源、导出 / 导入（JSON 文件批量备份恢复）、勾选批量删除、单条测速
- **失败源明细**：抓不到数据的源会提示，点「查看详情」可看到是哪些源失败、失败原因，可单源重试或隐藏
- **站点 Cookie（高级）**：给需要登录 / 风控的站点单独配置 Cookie，按域名自动匹配注入，只保存在本机
- **关闭最小化到托盘**：右下角常驻，双击图标随时打开
- **绿色免安装**：单文件 exe，双击即用
- **升级自动补新源**：老版本升级后自动追加新增的新闻源，原有设置全部保留
- **网页版每个访客独立配置**：置顶、隐藏、分类、外观都存在自己设备上，互不影响
